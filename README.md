# Physical AI Education site

A static site about undergraduate Physical AI education.

## Preview locally

Run `python3 -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish on GitHub Pages

Upload the files **inside this folder**, including `index.html`, `styles.css`, `script.js`, and `.nojekyll`, into the root of your repository. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**.

The diagrams are qualitative explanations, not experimental charts. The line-following scenarios are illustrative teaching examples.
